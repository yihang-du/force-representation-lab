# 相关工作与研究边界

核对日期：2026-10-01。以下基于论文摘要及官方项目说明，是立项定位，尚不是完整系统综述。表中的“本项目需要验证”是拟议方向，不代表已有结果或已证明的创新。

| 工作 | 已有内容 | 本项目需要验证 |
| --- | --- | --- |
| [ForceVLA](https://sites.google.com/view/forcevla2025) | 将六维力反馈与视觉语言信息通过力感知 MoE 融合，用于接触操作 | 在公平的力历史基线上，动作条件表征是否改善到位判断、恢复和迁移 |
| [FM-VLA](https://arxiv.org/abs/2607.18231) | 用重建预训练的 VAE 编码力历史，形成记忆 token 并条件化动作模块 | 除历史压缩外，物理与事件监督是否提供额外作用；不能把 force memory 本身作为新意 |
| [FORGE](https://arxiv.org/abs/2408.04587) | 在位姿不确定下学习力感知接触策略，并预测任务成功 | 明确区分低层控制效果、成功判断和表征学习收益 |
| [Improving Robotic Lego Assembly with Vibro-Tactile Feedback](https://publications.ri.cmu.edu/improving-robotic-lego-assembly-with-vibro-tactile-feedback) | CMU 2024 硕士论文；使用接触麦克风、力矩与相机辅助动作终止和结果判断 | 积木任务本身已有研究；需要可控误差、独立真值及跨物体实验 |
| [REASSEMBLE](https://arxiv.org/abs/2502.05086) | 装配与拆卸多模态数据，包含力矩和多视角视觉，支持任务状态与动作分段研究 | 可借鉴记录和标注设计，但与本项目积木接口、传感器及动作分布不同 |

## 对立项的影响

“加一个力编码器”“让 VLM 看力曲线”“积木压装成功判断”单独都不足以构成可靠的新颖性主张。更值得验证的组合是：

- 控制外观与目标几何，检验模型对接触过程的判断。
- 使用动作与实际运动条件，处理同一力变化的不同解释。
- 把独立完成真值与恢复闭环结合，避免只有离线分类。
- 冻结编码器测试跨物体和少样本任务迁移，明确表示层可复用的范围。

这些是本项目的研究假设，不是对已有方法缺陷的定论。不同文献的设备、力阈值和成功率不能直接搬到本套兼容积木。

## 实现前的精读顺序

1. ForceVLA 与 FM-VLA：输入接口、时间历史、融合位置、监督目标与公开实现条件。
2. CMU 积木论文：终止事件定义、末端执行器和失败类型。
3. FORGE：成功预测、允许力条件与位姿不确定的评估方式。
4. REASSEMBLE：时间戳、数据格式、对象分组和动作边界。
