# 数据与标注规范

## 记录单位

episode 从预夹持后的任务开始到最终验证结束；同一次任务的退开重试作为 attempt，不能拆成独立成功任务。所有模型窗口都能追溯到原始 episode、物体 ID、配置和时间范围。

建议每个 episode 独立目录，保存 manifest、传感器序列、相机视频/帧索引、动作记录、事件标注。仓库只跟踪规范和空模板，原始数据另存。

## 必需信号

| 信号 | 内容 |
| --- | --- |
| 原始力矩 | 设备时间戳、主机接收时间、Fx Fy Fz Tx Ty Tz、状态码、是否饱和 |
| 校正后力矩 | 偏置/重力补偿版本、坐标系、参考点与变换版本 |
| 机器人状态 | 实际 TCP 位姿、速度、关节状态、夹爪开口和可用的夹持反馈 |
| 动作命令 | 发出时间、接收/执行时间若可获得、原语、目标位姿/力、限幅后实际发送值 |
| 策略视觉 | 帧曝光或采集时间、相机 ID、标定版本 |
| 评估专用观测 | 侧视图像、装配高度、缝隙和格位真值；标明不可输入策略 |
| 运行记录 | 配置版本、模型 SHA、代码提交、随机种子、控制器版本、异常事件 |

单位统一为 N、N·m、m、rad、s。四元数顺序固定为 xyzw；任何其他顺序必须显式转换。保留原始数据，处理后信号不能覆盖原始值。

## 坐标和补偿

定义世界、装配、传感器、TCP、相机坐标系的轴和变换方向。统一命名如 T_assembly_sensor 表示把传感器坐标表达转换为装配坐标表达，并记录参考点。

力矩原点改变时需要平移项，符号由变换约定决定；用已知方向外载验证转换。偏置、工具重力与惯性影响应区分，静态重力补偿不等于所有动态项均已消除。

## 时间同步与因果性

使用单调时钟关联各信号，保留设备时间与接收时间。记录同步方法、估计偏移、抖动和漂移；样本率填写实测值，不假定各设备同频。

离线重采样只能使用决策时刻之前实际可用的信息。避免双向滤波、使用未来端点的插值，以及把迟到的图像当成已到达。保留缺失掩码和距最新样本的时间，超过有效时间窗即记录缺失或停止决策。

训练目标可在未来，但训练输入与归一化不能泄漏未来；传感器校正和预处理版本要可追溯。通过已知接触动作检查视频、位移和力变化的对齐。

## 标注层级

1. 几何结果：目标格位、装配高度、两侧缝隙、是否独立验证。
2. 事件与状态：free、contact、inserting、blocked、seated、unknown，附起止时间或时间区间。
3. 动作：继续、声明完成、卸载、调整、终止，以及执行的真实参数。
4. 异常原因：wrong_grid、incomplete、force_limit、slip、fixture_motion、timeout、data_loss 等，可多标签。

建议随机抽取至少 20% 的先导轨迹由第二名标注者独立复核，优先复核所有 ambiguous 和误报完成样本。记录一致率、分歧与仲裁过程；若仅一名标注者，明确说明并安排延迟复标。模型输出不显示给真值标注者。

seated 与 blocked 的标签不得由被学习的力阈值单独生成。若仅能确定某个区间内就位，用区间评估时延，不把任意帧当作精确真值。

## 分组与防泄漏

先按物理积木 ID 分组，再生成配对与窗口。同一积木参与多个配对时这些配对必须同属一个集合。磨损循环、采集日期、夹具版本也要记录，用于检查伪相关。

仅训练集计算标准化和特征选择。验证集选模型和阈值；测试集不能用于改阈值或挑视频条件。评估专用相机、人工偏移量、内部弹簧配置、最终结果和 episode 文件名不得输入模型。

增强需要保持物理关系：不能随意把力轴翻转而不相应变换运动和动作，也不能逐轨迹归一化抹去绝对力大小后宣称保留了幅值信息。

## 文件模板说明

[episode 模板](../templates/episode-manifest.example.json) 中 example=true，所有未知量使用 null。它是结构示例，不能计入真实数据。sample_paths 由实际数据存储位置填入，发布时需清理机器用户名和外部访问令牌。

[结果空表](../templates/results.csv) 每行汇总一个方法、种子、条件、数据版本的计数与指标；需要另存逐 episode 结果以重算置信区间。无样本分母对应的比率填 NA，不能填 0。

大文件保存时记录相对路径、大小、SHA-256 与访问方式。同步或归档前检查文件完整性；不要把 .env、访问令牌或传感器驱动凭证提交到 Git。
