# 力交互表征研究想法

## 核心动机

单个力值，例如“50 N”，缺少方向、持续时间、接触位置和动作背景，很难直接对应任务语义。相同的轴向力上升，可能来自正常压装、已经到位、错位受阻，或夹具移动。需要学习的是在给定动作和运动背景下，力信号如何反映接触过程，以及接下来应采取什么动作。

这份方案保留原始草稿的“raw value → representation → VLM → action → closed loop”主线。下面的方法结构和实验数量是具体化建议，不是原始草稿已经确定的实现。

## 表征定义

设六维力矩信号为 w，机器人实际状态为 s，已发出且时间上可获得的动作记录为 a。使用严格因果窗口：

```text
z_t = E_theta(w_[t-H:t], s_[t-H:t], a_[t-H:t))
prediction_t = D(z_t, image_<=t, task_goal)
action_t = policy(z_t, image_<=t, task_goal)
```

动作命令与实际运动分开记录。不能把当前待预测的动作、未来帧、最终成功标签或人工设置的真实偏移量输入编码器。

表征应保留：

- 物理量：力与力矩的方向、幅值、变化率，以及力与实际位移的关系。
- 时序事件：接触开始、持续插入、受阻、卸载、重试。
- 动作条件：正在向下推进、已经停止、主动退开或调整位置。
- 不确定性：部分接触状态从现有观测无法唯一识别，允许输出不确定并选择受限探测。

不要求某个 latent 维度等于“刚度”或“卡住程度”；通过独立探针任务检验这些信息是否可读出。物体内部状态并非总能从腕部力唯一恢复，目标格位仍需要视觉和位姿信息。

## 三个待检验假设

| 假设 | 实验 | 不支持该假设的结果 |
| --- | --- | --- |
| H1 力历史带来可用的接触信息 | 相同视觉和状态输入，比较有无力历史；分类与闭环都评估 | 仅提高训练集精度，留出物体或闭环无收益 |
| H2 动作条件与表征训练目标带来额外收益 | 同等输入、容量和控制器下，对比直接任务训练与表征预训练；移除动作条件 | 原始力历史的强基线相当或更好 |
| H3 表征可复用 | 冻结编码器，在新积木配对或按压任务上只训练小头 | 只有完整重新训练有效，冻结表征无优势 |

H1、H2 在积木上检验；H3 先测积木配对迁移，再尝试任务迁移。跨任务实验失败也应完整记录，不把任务内泛化称为通用力表征。

## 建议方法

第一版使用小型因果 TCN 或 GRU，将力矩历史、状态变化和过去动作编码成固定维度向量。初始候选窗口为 0.25、0.5、1.0 秒，latent 维度为 64 或 128；这些是验证集上的模型候选，不是传感器采样率或控制频率。保留 SI 单位原始值，归一化统计量只由训练集计算。

逐步增加训练目标：

1. 基础任务监督：接触阶段、当前是否已到位、建议动作原语。
2. 物理辅助目标：在已知动作条件下预测短期力变化或位移响应；目标来自未来，输入仍严格因果。
3. 结果辅助目标：预测一次尝试的完成概率；对齐到决策时刻，不能使用结束后的观测。
4. 可选语言对齐：把可验证事件映射为简短语义，如“横向载荷升高且推进停滞”；语言标签必须有传感器或几何证据。

先分别加入辅助目标并做消融，不在小数据阶段一次叠加所有损失。权重由验证集选择并冻结。若使用额外未标注数据或预训练算力，给直接力历史基线相同数据机会并单独报告成本。

## 与 VLM 和控制的关系

第一阶段让表征接小型状态头和动作头，检验它是否有信息。第二阶段再将其投影为 force tokens，送入多模态策略的融合层或动作模块；具体早期或后期融合需要对照，尚未固定。

VLM/VLA 负责较低频率的状态推断和动作选择；底层控制器执行受限原语，并持续读取传感器。模型延迟、原语执行时长和底层循环频率必须实测，不能由语义模型替代硬件控制回路。

只比较相同动作接口的系统。若基线和所提模型使用不同阻抗参数或恢复逻辑，无法把差异归因于表征。

## 值得争取的贡献

一个合理的研究目标是：在视觉相近但接触结果不同的条件下，学习可迁移且有时间含义的力交互表征，证明其在成功判断、失败恢复和新条件适应上的作用。

这还不是已确认的创新点。[ForceVLA](https://sites.google.com/view/forcevla2025) 已融合六维力与视觉语言信息；[FM-VLA](https://arxiv.org/abs/2607.18231) 已将力历史编码为记忆 token；积木接触反馈也已有研究。详见[相关工作](related-work.md)。写论文前需要进一步核对全文、实现和公平复现条件。
