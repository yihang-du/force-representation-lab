# 实验计划

本计划先回答“力表征是否帮助判断装配状态和恢复”，再回答“是否能接入 VLM/VLA 并迁移到其他接触任务”。所有数量为建议预算，未执行；设备未知参数见[设备表](setup-and-decisions.md)。

## 分阶段路线

| 阶段 | 工作 | 产物与通过条件 |
| --- | --- | --- |
| P0 装置与标定 | 固定积木、确认夹持、量测参考装配、校准传感器与同步 | 配置无关键空项，低速受控试运行可重复，独立成功判据可用 |
| P1 信号先导 | 5 对开发积木 × 3 条件 × 4 次，共 60 次 | 能同时观察正常插装和可恢复受阻；完成、未完成、错位标签有独立证据 |
| P2 数据与小模型 | 收集训练和验证数据，训练规则及学习基线 | 留出验证、标签一致性、延迟和动作接口检查通过 |
| P3 冻结测试 | 冻结模型、阈值、扰动分布，执行 240 次主对照 | 同时报成功率、误报完成、恢复、力和时间；失败不删去 |
| P4 多模态接入 | 用同一编码器投影为 force tokens，接已有 VLM/VLA | 相同动作接口下仍有收益，并报告推理延迟和新增成本 |
| P5 迁移与展示 | 按压探测；条件允许再做擦拭和彩色墙体 | 冻结编码器迁移结果与完整演示日志，分别报告 |

建议按实验工作量安排：P0 与 P1 约 3–5 个工作日，P2 约 1–2 周，P3 约 3–5 日；这是以设备和人员已到位为前提的估算。P4、P5 在前阶段结果支持后排期。

P1 若不能稳定复现接触事件，先改夹具和量测，不扩大采集。P2 若简单力历史基线已经解决全部条件，应增加留出配对或受控难度，而不是仅增加模型规模。

## 主任务与条件

从固定或预夹持上砖开始，到模型声明完成或触发停止条件结束。以[操作规程](brick-assembly-protocol.md)为准。

主测试包含 A 对齐、B 小横向偏移、C 小倾角三类；各类正负方向和轴分配在方法间配对一致。偏移量、倾角、速度与限值由开发数据标定后冻结。完整一格错装单列为完成判定的负例测试，不与小偏移受阻混为一谈。

首轮只研究一种上砖与下砖几何。改变几何、底座柔顺性、颜色和摄像头遮挡均单独作为后续条件，避免一次引入太多解释变量。

## 四个主基线

| ID | 输入与训练 | 回答的问题 |
| --- | --- | --- |
| B0 规则法 | 视觉或位姿定位，力矩和位移阈值，固定退开再对齐策略 | 学习方法是否超过可用的工程基线 |
| B1 无高层力输入 | 图像、实际状态、过去动作，直接任务监督 | 高层增加力信息是否有价值 |
| B2 力历史直接训练 | B1 输入加六维力历史，因果 TCN/GRU，直接任务监督 | 有力历史的小模型能做到什么程度 |
| B3 所提表征 | 与 B2 相同输入、编码器容量、动作头和任务监督，增加所提表征训练 | 表征学习目标是否带来额外收益 |

B2 也会学习特征，不能将它称为“没有 representation”。B3 对 B2 的差异是明确的预训练或辅助目标。所有方法共享底层控制器、力矩限制、动作集合、每次动作的范围、最大时长和最多 2 次恢复预算。B1 仅指高层不读力，底层仍保留相同力反馈。

优先主比较为 B3 对 B2；B3 对 B1 主要检验新增力模态。记录各方法的参数量、训练数据、预训练数据、训练步数、推理延迟及控制器版本，分别解释数据量和训练目标的作用。

原始数字串输入 VLM、将力画成曲线图片再输入 VLM 可作为附加接口基线；不替代 B2。若采用曲线图，绘图尺度、时间窗、处理延迟及数据带宽必须固定，不能手工选择最有利截图。

## 采集预算和数据切分

首轮建议准备 35 对积木：5 对仅用于先导，另 30 对用于正式实验。**每块上砖和下砖都只能属于一个数据集合**；若共享物体，按物理 ID 的连通组切分，而非只按配对名切分。

| 集合 | 配对数 | 每对条件与重复 | episode 数 | 使用方式 |
| --- | ---: | --- | ---: | --- |
| 先导开发 | 5 | 3 条件 × 4 次 | 60 | 标定协议，不进入最终测试 |
| 训练 | 15 | 3 条件 × 8 次 | 360 | 可用受控规则策略及人工纠错，保留成功与失败 |
| 验证 | 5 | 3 条件 × 4 次 | 60 | 选超参数和阈值 |
| 主闭环测试 | 10 | 3 条件 × 2 次 × 4 方法 | 240 | 冻结后一次执行 |
| 合计 | 35 个独立配对 |  | 720 | 不含后续扩展 |

样本量是可行性预算，不是已完成的统计功效论证。先核对箱内几何和数量是否足够；不足时减少独立配对并收窄泛化结论，不能重复使用同一块积木制造虚假的新物体数量。

训练和验证应跨至少两个采集时段，并记录日期、磨损与配对次数；测试在冻结后进行。按 episode 划分窗口，禁止同一次操作相邻片段跨训练和测试。训练、验证和测试中颜色与成功/失败条件不固定绑定。

训练学习曲线可从 360 条训练数据中抽取 90、180、360 条，按物体和条件平衡；不额外借用验证或测试数据。

## 测试流程与统计

每个“配对 × 条件 × 重复”组成一个匹配测试块，四种方法使用相同扰动设置。随机化块内方法顺序，记录磨损顺序，每次人工复位。未能精确复位时记录实际起点误差，不将模型不同的初始状态当作配对结果。

首轮学习方法采用预先指定种子 42，不按测试成绩挑种子。若初步结果支持，再对种子 7、2026 重复三个学习方法：完整三种子测试共 600 次（规则法 60 次，三个学习方法各 180 次），比首轮增加 360 次。

离线状态与完成判断比较使用所有方法共同的 B0 测试轨迹，共 60 条；在模型冻结后统一评分。另报告各模型自身闭环轨迹上的指标，说明它们的状态分布不同，不直接混为同一离线分类测试。

以物理配对为聚类单位计算 bootstrap 95% 区间和配对成功率差；多种子阶段另报种子均值、离散程度和分层区间。只有 10 个测试配对时区间可能很宽，须同时给原始计数与每对结果，不能把时间窗口数当成独立样本数。

## 指标定义

| 指标 | 定义与分母 |
| --- | --- |
| 最终任务成功率，主指标 | 满足目标格位与独立就位判据的 episode / 全部有效开始的 episode |
| 首次尝试成功率 | 未执行恢复即成功的 episode / 全部有效开始的 episode |
| 误报完成率 | 模型声明完成但独立真值不成功的 episode / 所有声明完成的 episode；分母为零则记 NA 并报告次数 |
| 失败状态被判完成率 | 在公共离线测试中的不成功状态被判成功数 / 真值不成功状态数；另报阈值、采样方式和混淆矩阵 |
| 恢复成功率 | 恢复挑战 B/C 中最终成功的 episode / 所有 B/C episode，作为可比主值；另报独立确认受阻子集，避免仅用模型自报卡住作分母 |
| 接触状态识别 | 公共测试上的逐事件/episode 汇总 macro-F1、blocked/seated 召回，排除 unknown 时报告覆盖率 |
| 力与力矩 | 每个 episode 的峰值、超过冻结限值的次数和持续时间；同时报告硬件停止 |
| 执行效率 | 全部 episode 的时长和重试次数；成功样本耗时另列，不能只展示快的成功 |
| 完成检测时延 | 独立就位事件至首次正确声明的时差；负值作为过早声明，未声明单列 |
| 计算开销 | 端到端决策延迟分位数、更新频率、超时比例 |

力矩限值触发、滑移、夹具移动、超时均计为运行失败并分类。仅在开始动作前发现的记录系统故障等预先定义的无效条件可剔除；保留原记录、原因和替补规则。运行后数据丢失记为结果不可判定，并报告保守成功率和缺失数量。

## 必做消融

按优先级开展，不要求首轮一次做全：

1. 单帧力 vs 历史力：检验时序信息，保持其余输入一致。
2. B3 vs 同容量 B2：检验辅助目标或预训练收益。
3. 移除过去动作，保留实际运动：检验动作条件的增益。
4. 移除实际位移信息：识别模型是否依赖力与运动的联合关系。
5. 训练与测试分别定义的时序扰乱控制：保留各通道边际幅值但破坏顺序；仅离线使用，不用于现场控制。
6. 冻结编码器与从头训练编码器：在新物体或少样本按压任务上比较。

测试时突然置零力是分布外诊断，只能作为敏感性检查；不能替代重新训练的 B1。扰乱或对齐偏移实验不应改变共享底层控制器。

## 两个扩展任务

### 按压探测

制作外观一致、按压头一致的模块，内部设置不同弹簧刚度、预压或限位深度。物理模块 ID、内部配置与外观颜色解耦。执行相同受限探测动作，记录力与实际压入位移，预测配置类别、是否已到限位，以及继续或停止。

刚度与预压不能只靠一个力值区分；需使用多个位移点。若机构允许，使用位移传感器量测真实压缩量，避免把机器人或底座变形当成弹簧压缩。先单独改变一个因素，再测试组合。

先标定少量模块做可行性试验。确认可重复后，每种配置至少制作多个物理实例，按实例切分。比较冻结积木编码器加小头、从头训练与完整微调，并给相同数量的目标域标签。零样本与少样本迁移分开命名。

### 连续擦拭

用可擦写板和固定擦头清除固定图案。统一初始笔迹、干燥时间、擦头磨损和照明；由独立图像测量残留面积，配合接触保持率、峰值力和执行时间评估。

先只改变板面倾角或支撑柔顺性中的一个因素，检查固定轨迹是否已经足够。若视觉和机械顺应本身就解决问题，不将擦拭成功作为力表征有效的证据。

## 继续与停止的判断

- 若 B3 仅超过 B1、未超过 B2：支持力模态有用，尚不支持专门表征方法有效。
- 若只在训练物体上有效：修正泛化主张，优先处理数据覆盖与泄漏。
- 若独立标签不可靠：暂停模型比较，先修正量测。
- 若闭环收益没有伴随更合理的力、恢复或完成判定：检查是否依赖更激进动作或不同控制参数。
- 若 MVP 成功：再投入 VLM/VLA 接入和跨任务迁移；保留所有负结果与方法变更记录。
