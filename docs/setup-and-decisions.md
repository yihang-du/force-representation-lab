# 设备信息与实验决策

创建日期：2026-10-01。以下是实施前的信息表，不代表设备已经配置完成。

## 已确认

- 研究方向：学习 force representation 并服务于多模态接触操作。
- 已购买：包装标注 1000PCS Building Blocks 的兼容式凸点积木。
- 任务重点：装配完成判断与卡住后恢复；按压为辅助验证，擦拭为连续接触扩展。
- 需要兼顾实验说服力和视觉演示效果。

## 当前建议决策

| 决策 | 理由 | 何时重新考虑 |
| --- | --- | --- |
| 先固定抓取或使用适配器 | 减少抓取失败干扰接触研究 | 装配协议稳定后 |
| 下砖用刚性固定夹具 | 避免底座移动成为主要信号 | 专门研究支撑柔顺性时 |
| 先做小模型，再接 VLM/VLA | 先判断信号和表征是否有效 | 留出测试和闭环有稳定收益后 |
| 成功标签独立于力信号 | 避免用阈值生成标签再声称学会阈值之外的信息 | 始终保留 |
| 按物理积木 ID 切分 | 避免同一积木的相邻片段跨集合 | 始终保留 |
| 先以私有研究仓库保存 | 方案尚在形成且没有结果 | 用户决定公开时 |

## 开始机器人采集前的完成条件

- [ ] 夹持和固定方式验证，整个路径无夹具干涉。
- [ ] 工具、力矩坐标系、偏置与重力补偿记录齐全。
- [ ] 独立成功判据及测量误差确定。
- [ ] 速度、力矩限值、动作步长、超时与卸载参数完成标定。
- [ ] 实测时间戳偏差、数据掉帧率和控制延迟。
- [ ] 在无模型驱动的受控试运行中检查记录与停止行为。
- [ ] 配置完成并冻结版本；模板中的 null 不能被默认值悄悄替代。
