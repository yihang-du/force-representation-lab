# 积木装配实验操作规程

## 目标与实物确认

任务是把上方积木装到指定格位并完全就位，遇到可恢复的错位时卸载、调整并重试。暂时固定抓取方式，把研究重点放在接触阶段。

已知物品仅为照片中的 1000PCS 兼容式凸点积木套装。先实测凸点间距、砖高、外形和配合情况。2×4、2×2 只表示凸点排列；若实际配对不合适，记录修改后再冻结任务几何。

## 最小装置

- 下方 2×2 积木凸点朝上，置于刚性限位窝，夹具固定到桌面。
- 上方 2×4 积木的中间两列与下方对齐；给目标格位和朝向建立唯一坐标。
- 机器人预夹持上砖两端的侧面，夹爪不要低于上砖底部；确认指尖在整个插入路径不会碰下砖或夹具。
- 若夹持稳定性不足，先使用固定适配器连接上砖。夹具版本作为实验变量记录，不能在同一对照中混用。
- 一台任务相机提供策略视觉；另设能看到两侧缝隙的侧视相机或量测装置，只用于真值。
- 推荐腕部六维力矩传感器。若只有关节电流估计力，记录估计器、带宽与限制，并相应缩小结论。

先使用刚性单站装置。彩色墙体演示后做，避免把墙体弯曲误当成插装接触。

## 积木筛选和参考状态

1. 挑选外观完好、可手动正常配合的积木，给每块唯一 ID。
2. 每对记录磨损、装拆次数、凸点尺寸和相对松紧。严重变形品不进入首轮主实验。
3. 手动确认目标格位完全就位，记录参考高度、两侧缝隙与相对位姿。
4. 重复装拆确认参考状态可复现，建立允许的几何误差与测量误差；阈值只用开发数据确定。
5. 重新安装工具或夹具后，重新确认参考，不沿用未知的零点。

上砖较长，沿长度方向偏移一整列仍可能咬合。必须检查指定格位，不能仅凭“牢固”或“高度正确”标成功。

## 力和运动标定

完成传感器预热与偏置检查，测量带工具负载时的重力影响，明确传感器轴、工具轴和参考点。将力矩变换到统一装配坐标时，同时变换力矩原点；仅旋转三维向量并不充分。保存原始力矩和校正后力矩。

逐步试验确定速度、位移步长、允许力与力矩、夹持范围、卸载距离和最大尝试时长。限值应低于机器人、传感器、夹具和物体中最保守的可接受范围，来源记录在配置中。**本仓库不预填通用牛顿阈值，不照搬其他论文数值。**

## 三类起始条件

| 条件 | 设置 | 目的 |
| --- | --- | --- |
| A 对齐 | 从目标位姿上方接近 | 观察正常接触、插入和完成 |
| B 横向偏移 | 在标定范围内设置小偏移，正负方向均衡 | 测受阻识别与重新对齐 |
| C 倾斜 | 设置小 roll 或 pitch，轴和正负方向均衡 | 测单侧接触与姿态恢复 |

偏移量和倾角在先导实验确定，需产生可重复且可恢复的困难。若所有条件都顺利插入，调整难度；若始终无法恢复，减小误差。测试时冻结条件分布，真实扰动参数仅给评估记录，不能作为策略输入。

另收集少量“错误格位但已咬合”的负例，用于检验成功判定。它与 B 类的半格错位受阻不是同一个问题，单独报告。

## 单次实验步骤

1. 核对物体 ID、配置版本、夹持稳定性、夹具位置和数据同步；在无接触状态记录短段基线。
2. 按计划设置起始条件；开始一个 episode，恢复重试仍属于同一 episode。
3. 执行接近；记录首次接触、推进、停滞和卸载等事件。
4. 策略在统一原语集合中选择继续推进、停止并声明完成、卸载退开、退开后调整位姿或终止。
5. 恢复必须先减小接触载荷，再进行横向或角度修正。调整步长、可用动作和重试预算对各方法一致。
6. 一旦触发底层限制、工具滑移或夹具移动，停止当前执行并记录原因。物理限制触发计入失败，不能直接删掉。
7. 结束后采集独立几何真值；保持相机和记录运行直到验证结束。验证帧不可回流给刚才的完成判定模型。
8. 人工复位并记录磨损及装拆次数；下一方法执行前恢复相同初始条件。

规划重试预算初值为每个 episode 最多 2 次恢复，需先导验证后冻结；预算不等于允许连续带载碰撞。

## 真值与状态标注

成功由独立侧视或量测确认：目标格位和朝向正确、达到允许的装配高度、两侧缝隙均在阈值内，且在已标定的卸载验证动作后保持。卸载验证不应变成未定义的拉拔测试。若工具影响观察，按统一流程移开或释放，并记录此时刻。

状态集合为 free、contact、inserting、blocked、seated、unknown。阶段可回退，例如 blocked → unload → contact；unknown 不强行并入成功或失败状态。最终结果另列 success、incomplete、wrong_grid、timeout、force_limit、slip、fixture_motion 等原因。

blocked 标签要求结合独立观察与实际运动停滞，不能只用待学习的力阈值生成。seated 状态同样由几何证据定位；时间精度不足时记录事件区间，不伪造精确帧。

## 演示效果

主实验稳定后，设置几个固定站点组成彩色低矮积木墙。镜头同时展示积木、力曲线、模型状态和下一动作，呈现一次真实的“受阻 → 退开 → 对齐 → 完成”。颜色与难度随机配对，不能红色总卡住、绿色总成功。

视频应标注是否加速、是否筛选片段。展示视频与完整评估日志分别保存，视频精彩程度不代替成功率。
